# The Audit — submission workspace

Graded take-home. Workspace root is this folder (`flam-ai-task-starter-kit/`).

## Layout

- `starterkit(1)/` — **read-only evidence**. Exact byte-for-byte mirror of the extracted starter-kit zip. Do not edit.
- `partA/`, `partB/`, `partC/` — analysis, scripts, memos (later phases).
- `artifacts/` — environment dumps, raw outputs, figures.
- `NOTEBOOK.md` — running lab log.
- `AI_USAGE.md` — AI assistance log.
- `requirements.txt` — pinned Python dependencies.

## Evidence copy (do not modify)

Working assignment files live only under `starterkit(1)/` (original zip filenames: `starter_kit/` + `__MACOSX/`, some files have extensions). See `NOTEBOOK.md` Phase 0. Do not duplicate that tree elsewhere in this repo.

## Operating rules

See `NOTEBOOK.md`. Evidence-first: no bug/metric claims without experiments; no fabricated numbers; full trace for every numeric claim; phase-gated work; no git commands from the agent.
